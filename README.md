## 📑 Curriculum Overview

### 🔹 Module 1: Frontend Fundamentals (HTML5 & CSS3)
Mastering the skeleton and skin of the web.
* **Semantic HTML**: Structuring documents for SEO and accessibility using proper tags.
* **CSS Box Model**: Deep dive into margins, borders, and padding.
* **Layout Systems**: Precision alignment using **Flexbox** and **CSS Grid**.
* **Responsive Design**: Crafting mobile-first interfaces with Media Queries.
* **Modern Styling**: Integration of **Bootstrap** components and **Tailwind CSS** for rapid UI development.

### 🔹 Module 2: JavaScript — The Logic Engine
Transitioning from static pages to dynamic, interactive experiences.
* **Core Fundamentals**: ES6+ syntax, template literals, and complex operators.
* **Advanced Arrays**: Functional programming with `.map()`, `.filter()`, and `.reduce()`.
* **DOM & Events**: Direct manipulation of the document tree and handling complex interactions like **Event Bubbling**.
* **Asynchronous JS**: Managing the Event Loop using Promises, `.then()/.catch()`, and `async/await`.
* **Networking**: Fetching data from public APIs using **Axios**.

### 🔹 Module 3: Backend Architecture (Node.js & Express)
Building the brain of the application.
* **Node.js Runtime**: Understanding the `process` object, `require` vs `import`, and module exports.
* **Express.js Framework**: Setting up servers, handling GET/POST requests, and parsing Query Strings/Path Parameters.
* **EJS Templating**: Creating dynamic HTML pages with logic-based rendering (`loops`, `conditionals`, `includes`).
* **RESTful Routing**: Designing standardized APIs for resource management.
* **Middlewares**: Implementing custom logic for authentication, logging, and error handling.

### 🔹 Module 4: Database & Deployment
Bringing applications to life in the cloud.
* **Persistence**: Database integration (MongoDB/SQL) and MVC (Model-View-Controller) design patterns.
* **Security**: Client/Server-side validations and authorization strategies.
* **Production**: Deployment workflows on **Render**, and integrating cloud services like **Cloudinary** (Storage) and **MapBox** (Geospatial data).

## 🚀 How to Run locally

1.  **Clone the Repo**:
    ```bash
    git clone [https://github.com/nishit-modh/fullstack-learnlog.git](https://github.com/nishit-modh/fullstack-learnlog.git)
    ```
2.  **Navigate to a module**:
    ```bash
    cd "36. BACKEND 2 (Express)"
    ```
3.  **Install Dependencies**:
    ```bash
    npm install
    ```
4.  **Start the Server**:
    ```bash
    node index.js
    ```
